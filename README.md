# 2013_bat_classification_using_audio_process_udes


Technology: MATLAB

# Project Overview

Developed an automated bat species classification system based on ultrasonic audio recordings using digital signal processing (DSP) techniques in MATLAB.

The project focused on extracting acoustic features from bat echolocation calls and applying signal analysis and classification algorithms to accurately identify species.

# Objectives

 * Process ultrasonic bat call recordings
 * Extract meaningful spectral and temporal features
 * Develop a classification model for species identification
 * Evaluate system accuracy and robustness

Technical Approach
1. Signal Preprocessing

    * Noise filtering and signal normalization
    * Band-pass filtering for ultrasonic frequency ranges
    * Segmentation of individual bat calls

2. Feature Extraction

    * Fast Fourier Transform (FFT) analysis
    * Spectrogram generation
    * Mel-Frequency Cepstral Coefficients (MFCCs)
    * Peak frequency detection
    * Time-domain and frequency-domain statistical features

3. Classification

    * Feature vector construction
    * Supervised classification (e.g., k-NN / SVM / Neural Networks if used)
     * Model training and validation
    * Accuracy and confusion matrix evaluation

Key Achievements

 * Successfully detected and segmented bat echolocation pulses
 * Achieved reliable species classification accuracy
 * Built modular and reusable MATLAB processing pipeline
 * Automated batch processing of multiple recordings

Skills Demonstrated

 * Digital Signal Processing (DSP)
 * Time-Frequency Analysis
 * Pattern Recognition
 * Audio Feature Engineering
 * Scientific Programming in MATLAB
 * Data Visualization & Model Evaluation
